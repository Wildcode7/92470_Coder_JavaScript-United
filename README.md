# Pre-Entrega 4 - JavaScript

## Simulador de productos

### Descripción
Este proyecto permite administrar una lista de productos mediante un menú interactivo desarrollado con JavaScript.

### Funcionalidades
- Listar productos utilizando `for...of`.
- Agregar productos al final con `push()`.
- Agregar productos al principio con `unshift()`.
- Eliminar el último producto con `pop()`.
- Eliminar el primer producto con `shift()`.
- Buscar productos con `includes()` e `indexOf()`.
- Reemplazar productos con `splice()`.

### Tecnologías
- HTML
- JavaScript

### Cómo ejecutar el proyecto
1. Abrir `index.html` en un navegador.
2. Seguir las instrucciones de las ventanas emergentes.
3. Abrir la consola del navegador con `F12` para consultar los resultados.
